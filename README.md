# 掼蛋（手机网页版）

在线游玩：https://renli19670413.github.io/guandan/

单文件网页游戏：`index.html`，用手机浏览器打开即可玩，无需安装、可离线。

- 你 + 对家（电脑）对抗左右两家电脑；电脑难度可选“全部普通/全部困难/对手困难·队友普通/对手普通·队友困难”（默认全部困难：记牌、整体拆牌规划、不乱用大牌炸弹、配合队友、残局拦截）
- 通用规则：两副牌、打级（2→A）、逢人配（红心级牌）、三带二/顺子/连对/钢板、炸弹/同花顺/天王炸、接风、进贡/还贡/抗贡、双下升3级、过A获胜（三次不过回2）
- **记牌器**：顶栏“记牌”打开，按点数显示“别人手里还有几张 / 我有几张 / 已出几张”，级牌和逢人配单独标注，并汇总三家剩余张数与本局炸弹数
- **出牌记录**：同一面板第二个标签，逐手记录本局谁出了什么牌、谁不要、每一轮谁收下、接风、进贡还贡和名次，自动跟随最新一手
- **悔牌**：顶栏“悔牌”退回到上一个自己的出牌点，可连续往回退；电脑思考时也能悔，手牌、已出牌、名次、出牌记录和炸弹统计一起回滚
- **实时牌型提示**：选中牌后牌桌中间立刻显示张数、牌型（含顺子/连对/钢板的点数范围）以及“可压过 / 管不上 / 牌型不合法”；“提示”也会说明推荐牌型并显示第几种出法
- **桌面牌型标签**：每一手出牌都带牌型标签，当前需要压过的那一手用金色高亮
- **报单/报双**：任一家剩 1 张或 2 张时提示并语音播报，张数徽标变红闪动
- 音效与语音报牌（可切换 音效+语音 / 仅音效 / 静音），出牌飞入、发牌、炸弹震屏＋火花动画
- 屏幕方向：跟随手机 / 竖屏 / 横屏（顶栏按钮一键切换，菜单→屏幕方向可选；与手机方向不一致时自动把画面转90°）
- 菜单→退出游戏：保存级数和积分后回到开始界面（安装到桌面的应用会直接关闭）
- 记分与战绩：每局按升级数记分（胜方+、负方−，过A再±5）；菜单→战绩可看总积分、胜率、头游/双下、连胜、按难度统计、炸弹统计和最近20局
- 理牌：手牌自动从小到大排列（同点数从上到下♠♥♣♦，百搭放最后），进贡/还贡后自动重排；选中几张牌点“理牌”归为一列放到最左，不选牌时点“还原”恢复
- 操作：点按或滑动选牌，“提示”循环推荐出法；进度自动保存在本机
- 电脑键盘快捷键：空格/回车 出牌、P 不出、H 提示、S 理牌、Z 悔牌、C 记牌器、L 出牌记录、Esc 关闭弹窗/面板

在 iPhone Safari / 安卓浏览器中打开后，可用"分享 → 添加到主屏幕"，像 App 一样全屏使用。

调试：`index.html?auto=1` 四家全部由电脑自动对局。

离线缓存版本：`sw.js` 中的 `CACHE`（当前 `guandan-v6`）。改动 `index.html` 后记得把它加一，老用户才会拿到新版。
