# 掼蛋（手机网页版）

在线游玩：https://renli19670413.github.io/guandan/


单文件网页游戏：`index.html`，用手机浏览器打开即可玩，无需安装、可离线。

- 你 + 对家（电脑）对抗左右两家电脑；电脑难度可选“普通/困难”（默认困难：记牌、整体拆牌规划、不乱用大牌炸弹、配合队友、残局拦截）
- 通用规则：两副牌、打级（2→A）、逢人配（红心级牌）、三带二/顺子/连对/钢板、炸弹/同花顺/天王炸、接风、进贡/还贡/抗贡、双下升3级、过A获胜（三次不过回2）
- 音效与语音报牌（可切换 音效+语音 / 仅音效 / 静音），出牌飞入、发牌、炸弹震屏动画
- 横屏模式：手机横放自动切换横屏牌桌；竖屏锁定时可点“横屏”按钮把画面旋转90°
- 记分与战绩：每局按升级数记分（胜方+、负方−，过A再±5）；菜单→战绩可看总积分、胜率、头游/双下、连胜、按难度统计、炸弹统计和最近20局
- 操作：点按或滑动选牌，"提示"循环推荐出法；进度自动保存在本机

在 iPhone Safari / 安卓浏览器中打开后，可用"分享 → 添加到主屏幕"，像 App 一样全屏使用。

调试：`index.html?auto=1` 四家全部由电脑自动对局。
